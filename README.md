# VKPlayground

This repository is for learning graphics programming with Vulkan and C++23. Python is needed for scripting purpose.

Prerequisites:
- Justfile (https://github.com/casey/just)
- Python 3.11+ (https://www.python.org/)
- uv (https://docs.astral.sh/uv/)
- CMake 3.21+ (https://cmake.org/)

Hardware Requirements:
- Vulkan 1.4 compatible device

## How to run:
- `just cli configure`
- `just cli run`

## Supported platforms:
- Windows
